`wspe` is macOS workspace/spaces manager.
It enables switching between macOS Desktop Spaces using `Cmd + <digit>`.

toc::[]

== Installation

=== 1. Obtain the Binary

Download pre-built release archives from GitHub Releases, or compile locally:

[source,bash]
----
cargo build --release
----

=== 2. Install and Register for System Startup

Run `./install.sh`, it copies the binary to `~/.local/bin/wspe` (or a custom directory specified via `--bin-dir`) and registers it as a macOS LaunchAgent (`uk.co.samuelwall.wspe`) so it automatically starts on system login:

[source,bash]
----
./install.sh
----

Options supported by `install.sh`:

* `--bin-dir <DIR>`: Custom install directory (default: `$HOME/.local/bin`).
* `--in-place`: Run the binary directly from `target/release/wspe` without copying.
* `--binary <PATH>`: Specify an alternate pre-built binary path.
* `--uninstall`: Unregister the LaunchAgent and remove the installed binary.

=== 3. Permissions

The Accessibility and Autiomation permissions are required to allow the app to intercept the global keyboard events and switch the workspace:

1. *Accessibility*:
   * Open *System Settings* -> *Privacy & Security* -> *Accessibility*.
   * Add and enable the installed binary (e.g. `~/.local/bin/wspe` or `target/release/wspe`).
2. *Automation*:
   * Open *System Settings* -> *Privacy & Security* -> *Automation*.
   * Ensure *System Events* is permitted for `wspe`. macOS will display an authorization prompt on your first space switch; approve this prompt.

== Usage

----
Cmd + <0-9>
----

=== Troubleshooting

* *Error: `AppleScript execution failed: ... not allowed assistive access`*:
  Ensure that your terminal or the `wspe` process has been granted access under *System Settings -> Privacy & Security -> Accessibility*.
* *Target space does not exist*:
  If you press `Cmd + 4` but only have 3 desktop spaces created, Mission Control will open and close without switching (or emit an error to `/tmp/wspe.log`). Add spaces via Mission Control before switching to them.
* *Conflicting Shortcuts*:
  If other applications intercept `Cmd + <digit>` at a higher priority or system level, ensure there are no overriding hotkeys defined in macOS *Keyboard Shortcuts*.
